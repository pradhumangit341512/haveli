THE UMMED HAVELI — FAVICON (TRANSPARENT, MARK ONLY)
===================================================
Just the gold TU monogram on a transparent background. No cream, no ring.

INSTALL
  1. Upload ALL files to the ROOT of theummedhaveli.com (next to index.html).
  2. Paste the block below inside <head> on every page.
  3. Hard-refresh: Ctrl/Cmd + Shift + R. If the old icon sticks,
     open theummedhaveli.com/favicon.ico directly to confirm it updated.

PASTE IN <head>
  <link rel="icon" href="/favicon.ico" sizes="any">
  <link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">
  <link rel="icon" type="image/png" sizes="16x16" href="/favicon-16x16.png">
  <link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon.png">
  <link rel="manifest" href="/site.webmanifest">
  <meta name="theme-color" content="#c8870a">

NOTE: iPhone/iPad home-screen icons don't support transparency — iOS fills
it with black. If you want a version with a white/cream square just for the
apple-touch-icon, ask and I'll add it.
